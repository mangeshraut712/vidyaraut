# Repo Instructions

## Documentation

- When updating `README.md`, prefer the established `vidyaraut` style:
  - centered title block
  - multiple badges
  - short bold tagline
  - quick links row
  - emoji-based section headings
  - grouped feature sections
  - tech stack table
  - project structure tree
  - installation, configuration, usage, deployment, contribution, and contact sections
- Keep README content accurate to the current repository state.
- Prefer concise, scannable Markdown over long prose.
- Use `docs/prompts/readme-style-prompt.md` as the reusable template for future README generation.

## Review Guidelines

- Flag inaccuracies in docs when routes, scripts, env vars, or deployment instructions drift from the codebase.
- Treat broken setup steps, outdated scripts, and incorrect deployment guidance as high-priority documentation issues.
